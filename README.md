# amarigio

Τελικό responsive portfolio site σε Next.js, έτοιμο για GitHub Pages.

## Τοπική προβολή

```bash
npm install
npm run dev
```

Άνοιξε το `http://localhost:3000`.

## GitHub Pages

1. Ανέβασε όλα τα αρχεία σε public GitHub repository με branch `main`.
2. Πήγαινε Settings > Pages.
3. Στο Source επίλεξε GitHub Actions.
4. Άνοιξε το Actions και περίμενε το workflow `Deploy Next.js to GitHub Pages` να ολοκληρωθεί.
