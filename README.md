# amarigio website

Responsive Next.js site configured for static export and GitHub Pages.

## Local preview

```bash
npm install
npm run dev
```

## Publish

1. Create a GitHub repository and upload all files.
2. Use `main` as the default branch.
3. Open **Settings > Pages** and set **Source** to **GitHub Actions**.
4. Push a change. The included workflow builds and publishes the site.

## Replace placeholders

- Update the Instagram URL in `app/page.tsx` if needed.
- Replace the graphic placeholders in the collection cards with your product photos.
- Update text, contact details and SEO metadata in `app/layout.tsx`.
